# 五官镜像 · Face Feature Mirror

摄像头看着你，页面里**只画五官**——眼、眉、鼻、嘴，不画整张脸。你转头、挑眉、眨眼、张嘴、
吐舌头，屏幕上的五官就跟着动，而且方向是**照镜子**的。

### 👉 在线直接用：<https://yumi-06.github.io/face-mirror/>

打开网址 → 允许摄像头 → 谁坐到电脑前，就会弹出画风选择（四个格子是他自己五官的实时预览）。

- 四种画风：**可爱 / 抽象 / 像素 / 水墨**
- 五种配色：蜜桃 / 薄荷 / 银河 / 糖果 / 宣纸
- **多人一起用**：最多同时跟 4 张脸，**一人一套五官、各选各的画风**；
  点画面里的人（或 `Tab` / `Alt+1–4`）切换当前这位
- 五官大小、跟随头部移动、表情幅度都可调
- `H` 收起面板 · `F` 全屏 · `S` 拍一张 · `C` 换画风 · `D` 调试视图 · `1–4` 切画风 ·
  `Tab` 换人 · `Alt+1–4` 选第 N 位
- 没有检测到人脸时，五官会"睡着"飘在中间（闭眼 + `z z z`），底下提示你怎么把脸放进来

## 隐私

**视频帧只在你的浏览器内存里过一遍：不联网、不上传、不存储。**
人脸模型与运行时随页面一起下载到本机，之后全部计算都在本机完成，没有任何服务器参与。
设置只存在浏览器 localStorage 里，随时可以"重置"。

## 离线使用（不需要网络）

下载仓库里的 **`五官镜像.html`**（约 17 MB，模型 / wasm / 运行时全部内联在这一个文件里），
在资源管理器里双击、用浏览器打开即可 —— 不需要服务器、不需要命令行、不需要联网。

Windows 上还有两个省事的入口：`打开-五官镜像.url`、`打开-五官镜像.bat`。

想跑源码版（改代码时用）：双击 `启动-面容镜像.bat`，它会在 `127.0.0.1` 上起一个只监听本机的小服务。

## 原理

```
摄像头 ─▶ MediaPipe FaceLandmarker（本地 wasm）─▶ 478 关键点 + 52 个表情系数
                                                   │
                                      src/signals.js│ 信号层
                                                   ▼
                                       五官状态（位置 / 开合 / 表情标量）
                                                   │
                                      src/draw/*.js│ 四个画风
                                                   ▼
                                                 canvas
```

几个关键设计决定（都是被实测数据逼出来的）：

- **位置全部来自关键点自身**：眼心、眉心、鼻尖、唇心各用自己做镜像映射，所以转头、点头、
  前后移动、歪头都是天然跟随的，不需要单独解算头部姿态。
- **表情比例一律用瞳距归一化**，不用"额头—下巴"高度：脸贴到画面边缘时额头关键点会被截断，
  用脸高会让所有比值一起爆掉。
- **自适应基线**：每个人静止时的唇缝宽度、眉距、眼睛开度都不一样。眼睛开度取"近期最大值"，
  唇缝取"近期最小值"，眉距在表情平静时缓慢漂移收敛 —— 所以眯眼的人和圆眼的人都能正确判睁闭。
- **眨眼快闭慢睁**：关眼时间常数 22 ms、睁眼 85 ms，眨眼不会糊。
- **各向同性映射**：关键点的 x/y 是按画面宽高分别归一化的，直接用同一比例会把脸纵向拉伸 4/3。

加一个画风：在 `src/draw/` 放个新文件导出 `draw(ctx, state, env)`，在 `src/draw/index.js` 注册，
再到 `src/config.js` 的 `STYLES` 加一行即可，信号层不用动。

## 从源码构建

```bash
# 1) 浏览器版本：直接用仓库根目录的 index.html（需要本机服务，见上）
# 2) 生成"单文件离线版" 五官镜像.html
node _tools/build_standalone.mjs
# 3) 重新下载 MediaPipe 运行时与模型到 vendor/（需要外网）
node _tools/fetch_vendor.mjs --force
```

`五官镜像.html` 是**构建产物**：改完 `src/` 或 `index.html` 要重跑第 2 步。

## 浏览器要求

较新的 **Edge / Chrome**（需要 WebAssembly SIMD 与 `getUserMedia`）。Firefox 未测。
在线版走 https，摄像头权限正常；离线版走 `file://`，同样可用（file:// 是安全上下文）。

## 已知限制

- 单人：画面里有第二个人时会认最突出的那张脸。
- 逆光、侧脸超过约 60°、口罩遮住半张脸时关键点会不稳。
- 认"人"靠的是"人脸是否离开画面 ≥ 5 秒"这个事件，不是人脸识别 —— 刻意不做身份识别，
  也不存任何生物特征。
- 移动端未做适配（可以打开，但面板偏大）。
